# 🦴 Fracture Detector AI

A full-stack web app that uses Roboflow-trained computer vision to detect bone fractures in X-rays.

## 🔧 Tech Stack
- React (Vite) frontend
- Flask backend (Python)
- Roboflow API (YOLO-based model)
- GitHub for version control

## 🚀 How to Use
1. Upload an X-ray image
2. The Flask backend sends it to Roboflow
3. Receive a detailed fracture report

## 📁 Project Structure
- `/frontend`: React app
- `/backend`: Flask + API connector
